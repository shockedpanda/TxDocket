# Base Wallet Records

Turn Base wallet activity into clean transaction schedules.

A free tool that helps Web3 teams, accountants, and operators turn raw onchain transactions into finance/accounting-ready records.

## Features

- Enter any public Base wallet address
- Generate a clean token transfer schedule
- View date, token, amount, counterparties, and transaction hashes
- Export CSV for spreadsheets
- Free to use — no wallet connection required

## Disclaimer

This tool provides an operational documentation layer for wallet activity. It is not tax advice, legal advice, AML screening, sanctions clearance, blockchain forensics, accounting conclusions, or compliance certification. Always consult a qualified professional.

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- Blockscout Base API

## Getting Started

git clone https://github.com/shockedpanda/base-wallet-records.git
cd base-wallet-records
npm install
npm run dev

Open http://localhost:3000
